- Правило B «признак работы на заказ»: перепроверено out-of-sample (0.98), но только на Riyadh — Jeddah не проверен
- Правила A и C проверены только in-sample; 2 склейки не проверены (`merge_qa.md`)
- chain_rate по имени в B завышен SEO-одинаковыми названиями (одно имя у 16 карточек)
- BNPL-детекция только по главной странице; вид маркера `icon` не верифицирован; Salla недоступна скрипту (Cloudflare challenge)
- Порог сети (5 точек) считает филиалы только внутри двух кругов поиска (пример: Ram Clinics) → штраф за размер в скоринге
- BNPL-статус известен не для всех: загружено A 109/250, B 46/289 eligible; четверть своих сайтов закрыта для скриптов (не обходим)
- Критерий C на выборке 20: интервал Уилсона 0.48–0.86; у магазина 1 ответ под сомнением (артефакт терминала), вердикт от него не зависит

- Имя ЛПР есть у 9% кандидатов (в основном из названия клиники); чек не измерен (цены на странице у 12 из 519); арабские опенеры — AI-drafted, без ревью носителя
